Everything a software factory needs.

fctl runs Claude Code agents in sandboxes on machines you own, around the clock, on your Claude subscription. These are the parts that make that work: for the people who hand out the work, for the agents that do it, and for whoever has to keep it all running.

Sessions

Agents at work in plain sight: live transcripts, their pull requests and checks, and follow-ups that bring them back.

Watch a session → Workspaces and projects

A workspace for each team, a project for each repository, and settings that decide what its agents may do.

Set one up → Team management

Invitations, roles and sessions you watch and steer together, with sign-in by Google or a passkey.

Bring your team → Sandboxes

A fresh Linux machine for every session, in Apple's container runtime or Docker, from an image you can make your own.

Look inside → Linear

Delegate a ticket to fctl the way you would to a teammate, and get a pull request back, with the ticket kept current.

Hand one over → Review agents

An agent reads every new commit of every pull request, yours and your team's included, and says what it found where it matters.

Read a review → Memory and retrospectives

Agents leave notes for the agents after them, and say how each piece of work went, so the project gets easier to work on.

See what they learned → Runners

The Macs and servers you and your team already have, turned into the factory floor with one command each.

Bring one online → Schedules

Dependency updates on Tuesdays, a flaky test hunt on Saturdays, benchmarks every night: work that starts on its own.

Set a schedule → Access tokens

Let a chat bot, a CI job or another agent start sessions as you, with a token that can do just that, in one project, for a while.

Make one → Sign-in and security

Passkeys, an authenticator app, and a second look before anything sensitive, for an app that can run code on your machines.
