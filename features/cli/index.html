Features/The CLI

All of fctl, from your terminal.

Everything the app does, the CLI does too: start a session and watch it stream, steer it, search every transcript, manage projects, runners and schedules. And every command answers in JSON when a script, a pipeline or another agent is the one asking.

The floor, in a dozen lines.

fctl sessions lists what's at work and what finished, across your workspaces or in one, and fctl show tells you everything about one: who asked, its ticket, its branch, its pull request and checks, where it runs and how full its context is. Sessions go by shop#231, their id or their link, whichever you have to hand.

Steer it like you'd steer a colleague.

A message reaches the agent at its next step, with files attached if you like. Interrupt the turn it's on, stop it, resume it tomorrow with a new task, or share it with a teammate. The same session is in the app, on your phone and in your terminal at once, and everyone sees the same thing.

Made for scripts, and the agents that write them.

With -d, fctl run returns as soon as the session exists; with --json, it says so in a form jq can read. Check on it when you like, read what it did, and move on: the same commands work in a cron job, a GitHub Actions step, or another agent's tool call.

  • Signed in as you, or as a token. fctl login on your machine, FCTL_TOKEN anywhere else.
  • A guide for agents. The docs say how a program should drive fctl, and what to avoid.
ci@build-7 ~/platform

id=$(fctl run -p platform -d --json -f tasks/flaky.md | jq -r .id)

# …once its turn has ended

fctl show $id --json | jq '{status, pr: .pull_requests[0].url}'

And the rest of the factory.

Every capability of the app has its command. A few of them:

Sessions

  • fctl runStart one, and follow it
  • fctl attachStream it and type messages
  • fctl logs -fThe transcript, as it grows
  • fctl searchEvery transcript, by what was said

Projects

  • fctl projects setModel, setup script, image, sizes
  • fctl projects secretsSecrets for its sandboxes
  • fctl projects reposOther repositories it may use
  • fctl projects ticketsLinear or GitHub issues

Reviews and memory

  • fctl review settingsTurn review agents on
  • fctl review startReview a pull request now
  • fctl memoryWhat agents left for each other
  • fctl retro listHow each piece of work went

Runners and teams

  • fctl host installTurn this machine into a runner
  • fctl host drainFinish its sessions, take no new ones
  • fctl workspaces inviteBring someone in
  • fctl shareOne session, with one person

Automation

  • fctl schedules addWork that starts on its own
  • fctl schedules runNow, with context
  • fctl tokenA token for a tool, with limits
  • fctl ticketTickets, from an agent's sandbox

You

  • fctl loginThrough your browser and passkey
  • fctl claude connectYour Claude subscription
  • fctl account two-factorAn authenticator app
  • fctl self updateThe newest fctl
