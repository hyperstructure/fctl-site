Three steps from a spare Mac to agents at work.

  1. 01

    Turn a machine into a runner

    One command registers it and starts it as a service. Each session gets its own lightweight Linux VM — Apple's container runtime on a Mac, Docker on Linux — with a fresh clone, its own branch and your project's setup script. 

    $ fctl host install

    Runners → Sandboxes →

  2. 02

    Connect your Claude subscription

    Sign in once with your Pro or Max plan. fctl refuses API keys, checks every session's billing source, and pauses a session before it would draw on paid extra usage. Rate limits pause and resume on their own.

  3. 03

    Give agents work

    From the app, the terminal or Claude on your phone. Agents commit on their branch, push, and open a pull request when they are done. Message them any time to steer. 

    $ fctl run -p my-app "Add a dark mode toggle"

    Sessions → The CLI →

The rest of the factory.

One agent in a terminal is a tool. These are the parts that make many of them a factory you can leave running: reviews on every commit, tickets handed over, work that starts on its own, and the machines it all runs on.

Every feature, from sessions to the CLI →

Made for the long run.

Follow along anywhere

Sessions join Claude's Remote Control, so they show up in Claude on your phone and desktop, where you can read along and reply.

Work as a team

Share projects and sessions. Everyone sees the same live transcript, who else is watching, and anyone with access can steer the agent.

A terminal that keeps up

fctl attach streams any session into your terminal, token by token. send, interrupt and stop steer it from scripts and CI.

Yours to run

The control plane runs on Cloudflare, or in one container anywhere; agents run on your hardware. Deploy your own instance with one command. MIT licensed.

Built not to drop work

A Rust core end to end. Agents journal every event before it leaves the sandbox, links reconnect and replay, hosts pick running sessions back up after a restart, and agents leave notes for the agents after them.

Around the clock

Hosts keep their machine from sleeping, idle sessions wind down on their own, a queue holds work until a runner is free, and access tokens let your other tools start work as you.

How the pieces fit.

You talk to the control plane. Your machines dial out to it and run each session in a sandbox of its own, so nothing on your network listens for anyone.
