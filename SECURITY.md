# Security policy

Please report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** on this repository, not in a public issue. We acknowledge
reports within three working days.

This repository serves https://fctl.sh, including `/install`, the script people
pipe to `sh`, and the release archives under `/releases`. How fctl itself
handles credentials, sandboxes and billing is in
[fctl's security docs](https://fctl.sh/docs/security/).
